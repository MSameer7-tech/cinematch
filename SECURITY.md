# Security Policy

## Supported Versions

Currently, only the latest `v1.x` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within CineMatch, please DO NOT disclose it publicly.
Instead, send an e-mail to the repository maintainer. All security vulnerabilities will be promptly addressed.
